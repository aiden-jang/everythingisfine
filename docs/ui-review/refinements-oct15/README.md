# Source citations and field details

Copy citation keeps each earthquake agency's magnitude, scale, origin and received
time separate, with its source and the current view link. Selectable storm, fire,
flood and volcano cards also expose citations. Episode dates stay episode dates;
missing observations are not invented. Clipboard refusal reveals selectable text
and a retry action. Field autofill and selection follow the existing dark palette.

- [Desktop citation recovery](refinement-citation-1440.png)
- [Phone citation recovery](refinement-citation-390.png)

The browser review uses recorded feeds, refuses clipboard access, then checks a
successful retry. It also checks that the copied link names the current event.
No public provider or paid service is needed for the journey. Native clipboard,
physical keyboards and actual autofill remain device checks.
